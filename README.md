## GPIO Lab
The GPIO lab interfaces with the following:

* User buttons and LEDs of the TI MSP432 LaunchPad
* PMOD SWT (4 Slide Switches) - [Product Link](https://digilent.com/reference/pmod/pmodswt/start)
* PMOD 8LD (8 LEDs) - [Product Link](https://digilent.com/shop/pmod-8ld-eight-high-brightness-leds/)

## 1. Overview

This lab introduced the general concepts surrounding the General-Purpose Input/Output (GPIO) interface for the MSP432. Students were able to work on understanding the basic functionality behind the interface, namely reading input from the two switches, controlling the two LED outputs, and observing the values of the memory-mapped registers of the Input/Output ports.

## 2. Components Used

- 1 USB-A to Micro-USB Cable
- 1 PMOD 8LD
